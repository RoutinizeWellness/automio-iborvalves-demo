# Demo Automio · IBOR Valves

Demo de compras y calidad para IBOR Valves (válvulas de bola forjadas, Castellar del Vallès).

Módulos: confirmaciones de proveedor comparadas con el pedido (fecha, cantidad, material, certificado EN 10204 3.1), control de entrada de material (colada, composición, dureza, marcado), dossier de trazabilidad por válvula, pedidos, proveedores y borradores de mensaje que se aprueban antes de enviarse.

Los hechos sobre IBOR (certificaciones, ensayos, productos, origen del material) salen de https://www.iborvalves.com. Todo lo demás es ficticio: proveedores, pedidos, coladas, certificados, resultados y cifras. La demo no está conectada a ningún sistema real y no envía nada.

Ver la demo: https://routinizewellness.github.io/automio-iborvalves-demo/
